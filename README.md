# 🩺 Diabetes Prediction using Machine Learning

This project predicts whether a person is likely to have diabetes based on medical parameters using Logistic Regression.

## 🧠 Tech Stack
- Python  
- Pandas, NumPy  
- Scikit-learn  
- Matplotlib  

## 🚀 Features
- Data preprocessing and scaling  
- Model training using Logistic Regression  
- Prediction for new patient data  

## 🎯 Example Output
Input: Glucose=150, BMI=28.5, Age=35 → ⚠️ Likely Diabetic
